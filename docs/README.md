## 四、产出顺序

文档按软件工程流程顺序产出，与开发阶段对应：

1. **需求阶段** → D1 需求规格说明书、U1 用例图
2. **设计阶段** → D2 概要设计、D3 详细设计、D4 数据库设计、U2 类图、U7 ER 图
3. **实现阶段** → U3 / U4 时序图、U5 活动图、U6 状态图
4. **测试阶段** → D5 测试用例与测试报告
5. **收尾** → D6 项目总结报告
