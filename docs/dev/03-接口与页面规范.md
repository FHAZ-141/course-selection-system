## 二、权限矩阵

| 路径前缀 | 学生 | 教师 | 管理员 | 未登录 |
| --- | --- | --- | --- | --- |
| `/health`、`/login` | 公开 | 公开 | 公开 | 公开 |
| `/`（首页） | ✅ | ✅ | ✅ | → 跳登录 |
| `/courses/**` | ✅ | ✅ | ✅ | → 跳登录 |
| `/enrollments/**` | ✅ | ❌ 403 | ❌ 403 | → 跳登录 |
| `/announcements/**` | ✅ | ✅ | ✅ | → 跳登录 |
| `/teacher/**` | ❌ 403 | ✅ | ❌ 403 | → 跳登录 |
| `/admin/**` | ❌ 403 | ❌ 403 | ✅ | → 跳登录 |

### 实现方式

- 登录校验：`requireLogin`
- 角色校验：`requireRole('student')` / `requireRole('admin')` 等，见 `src/middleware/auth.js`
- **每个路由模块在文件顶部统一挂载**，不要逐个路由单独判断，避免漏加：

  ```js
  router.use(requireLogin, requireRole('admin'));
  ```

> ⚠️ **加新路由时的必做检查**：问自己"这个页面哪些角色能访问？"，
> 然后确保 `router.use(...)` 里挂上了对应的 `requireRole`。
> 漏挂 = 越权漏洞，冒烟测试里有专门的越权用例（学生访问 `/teacher` 应得 403）。

## 三、响应约定

### 3.1 页面请求（返回 HTML）

| 场景 | 做法 |
| --- | --- |
| 成功 | 重定向到目标页（`res.redirect`），避免刷新重复提交 |
| 参数校验失败 | 重新渲染当前页，带上 `error` 变量显示提示，**保留用户已填内容** |
| 未登录 | 302 跳 `/login?next=<原路径>`，登录后跳回原路径 |
| 无权限 | 403 渲染 `views/error.ejs` |
| 找不到 | 404 渲染 `views/error.ejs` |
| 服务器错误 | 500 渲染 `views/error.ejs`，同时打印到控制台 |

### 3.2 脚本 / 接口请求（返回 JSON）

用于并发压测脚本等场景，约定统一格式：

```json
{ "ok": true, "data": { } }
{ "ok": false, "message": "课程已满" }
```

未登录时返回 HTTP 401 + `{"ok":false,"message":"请先登录"}`（由 `requireLogin` 处理）。

## 四、命名规范

| 对象 | 规则 | 示例 |
| --- | --- | --- |
| 数据库表 / 字段 | 小写 + 下划线 | `class_time`、`day_of_week` |
| JS 变量 / 函数 | 小驼峰 | `courseId`、`findConflicts()` |
| 路由文件 | 复数名词 | `courses.js`、`enrollments.js` |
| 服务文件 | 单数 + Service | `enrollmentService.js` |
| 视图文件 | 小写 + 下划线 | `course_list.ejs` |
| URL 路径 | 小写 + 连字符，资源用复数 | `/admin/courses/new` |
| CSS 类名 | 小写 + 连字符 | `.stat-card` |
| 常量 | 大写下划线 | `DEMO_PASSWORD` |

## 五、视图渲染约定

所有页面模板必须遵循同一结构，保证导航栏与页脚一致：

```ejs
<%- include('partials/header') %>

<!-- 页面内容 -->

<%- include('partials/footer') %>
```

`res.locals` 中可用的公共变量（由 `middleware/auth.js` 注入）：

| 变量 | 说明 |
| --- | --- |
| `currentUser` | 当前登录用户对象，未登录为 `null` |
| `roles` | 角色枚举：`{ student: '学生', ... }` |
| `weekTypes` | 周次枚举：`{ all: '每周', odd: '单周', even: '双周' }` |
| `periods` | 节次与时间的映射表 |
| `activePath` | 当前路径，用于导航高亮 |
| `appName` / `appVersion` | 应用名与版本号（`app.js` 中注入） |

## 六、闪现提示（Flash）约定

目前使用最简方案：**错误直接随 `res.render` 传参**，成功则重定向到目标页。

若将来需要跨重定向传递提示消息（例如"选课成功"），再引入 session 中的 `flash` 字段，
统一在 `attachUser` 中间件里取出并清空，通过 `res.locals.flash` 供模板使用。
