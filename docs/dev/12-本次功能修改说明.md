# 本次功能修改说明（2026-10-23）

> 本文件记录按需求方要求增加的管理员账号管理、管理员课程名单调整和教师课程名单操作。
> 修改已在本地完成验证并提交部署，验证结果见第七节。

## 一、需求范围

1. **管理员账号管理与注册**：查询账号、按角色筛选，创建学生/教师/管理员账号，编辑资料、重置密码；在安全条件满足时删除账号。
2. **管理员调整学生选课**：从课程名单页添加学生、退选已选学生、将学生移出候补队列；这些操作不受选课窗口限制。
3. **教师管理课程名单**：从教师端进入本人课程名单，为本人课程中当前已选的学生办理退课。

这里的“注册账号”是**管理员代为创建账号**，不代表开放学生自主注册。管理员代办只免除选课窗口检查；课程状态、重复选课、时间冲突、容量与候补队列上限仍按既有规则检查。

## 二、管理员账号管理

### 页面与操作

- `/admin/accounts`：按账号、姓名、院系搜索，并按学生、教师、管理员筛选。
- `/admin/accounts/new`：创建账号，填写账号、姓名、角色、院系、可选年级和初始密码。
- `/admin/accounts/:id/edit`：编辑账号资料；另外提供独立的密码重置和删除操作。
- 创建与密码重置要求密码为 6~128 个字符。密码不回显，沿用 `utils/password.js` 的 scrypt 算法与每账号随机盐。
- 账号格式为 3~20 位字母、数字、下划线或连字符；账号全局唯一。学生年级可留空，填写时限制为 1~8。

### 删除与角色变更约束

- 当前登录管理员不能修改自己的角色，也不能删除自己。
- 账号被课程、选课记录或公告引用时不能删除，以免破坏外键关系；页面会提示先维护关联数据。
- 有授课课程的教师账号、有选课记录的学生账号不能修改角色。无关联记录的账号可以修改角色。
- 这些约束在服务层检查，不只依赖页面控件。

## 三、管理员课程名单管理

课程管理列表新增“管理名单”入口，进入 `/admin/courses/:id/enrollments` 后可查看已选学生与候补队列。

### 加入课程

管理员输入学生学号，系统确认账号存在且角色为学生，然后调用 `enrollmentService.adminEnroll()`。该方法复用现有选课事务并设置内部 `ignoreWindow` 选项，因此只跳过选课窗口检查：

- 停开课程仍不可选；
- 已选或已在候补的重复操作仍会被拒绝；
- 时间冲突仍会被拒绝；
- 有余量时登记为已选；
- 满员时依旧受候补容量上限约束，符合条件后加入 FIFO 队列。

### 退课与候补管理

- 对已选学生办理退课，复用 `enrollmentService.drop()` 的事务、课程行锁和候补自动补位逻辑。
- 对候补学生可执行“移出候补”，复用 `enrollmentService.cancelWaitlist()`。
- 两项操作均不检查选课窗口。候补移出不释放已占用名额；已选学生退课会释放名额并尝试自动补位。

## 四、教师课程名单管理

- 教师课程列表将入口标为“管理课程”，课程名单仍展示已选名单和候补队列。
- 已选名单增加“办理退课”操作；候补名单没有退课按钮。
- `teacherService.dropStudentFromMyCourse()` 在服务层确认课程属于当前教师，并确认目标学生是该课的学生且状态为 `enrolled`，之后调用共享退课服务。
- 退课成功后仍按原逻辑为合格候补学生自动补位。尝试操作他人课程返回 403，课程不存在返回 404。
- 教师仍不能编辑课程字段或直接移除候补学生。

## 六、接口清单

| 方法 | 路径 | 用途 | 权限 |
| --- | --- | --- | --- |
| GET | `/admin/accounts` | 搜索与筛选账号 | 管理员 |
| GET | `/admin/accounts/new` | 新建账号表单 | 管理员 |
| POST | `/admin/accounts` | 创建账号 | 管理员 |
| GET | `/admin/accounts/:id/edit` | 编辑账号表单 | 管理员 |
| POST | `/admin/accounts/:id` | 更新账号资料 | 管理员 |
| POST | `/admin/accounts/:id/password` | 重置密码 | 管理员 |
| POST | `/admin/accounts/:id/delete` | 删除无业务引用的账号 | 管理员 |
| GET | `/admin/courses/:id/enrollments` | 查看已选与候补名单 | 管理员 |
| POST | `/admin/courses/:id/enrollments` | 窗口外为学生办理选课 | 管理员 |
| POST | `/admin/courses/:id/enrollments/:studentId/drop` | 退选学生并尝试补位 | 管理员 |
| POST | `/admin/courses/:id/enrollments/:studentId/cancel-waitlist` | 移出候补队列 | 管理员 |

所有写操作继续采用 POST + 重定向及 flash 回执，受现有模块级 `requireLogin` / `requireRole` 保护。新增操作没有增加数据库表或字段；SQLite 与 PostgreSQL schema 无需变更。
